# Personal portfolio

Open `index.html` in a browser. It uses Bootstrap 5 from a CDN alongside its own stylesheet and a small navigation script. Replace the sample name, email address, and project descriptions with your own details before publishing.

To document the version control practical, initialize a Git repository in this folder, make an initial commit, create a feature branch, make a visible change, and merge it through a GitHub pull request. Publish the main branch with GitHub Pages. Record the repository, pull request, and live URLs in the submission.
